VI. R ESULTS
Based on the construction discussed in Section IV, we perform
a search for C = [ [n,k :m,d ] ]2 codes with distance d ≥ 3.
We start with the self-dual codes from the classiﬁcation in
[?], [ ?]. In a ﬁrst step, we construct impure quantum codes
[ [n, 1,d ] ]2, and then look for additional vectors for the encoding
of classical information, resulting in an [ [n, 1:m′,d ] ]2 hybrid
code. In some cases it turns out that we can in fact encode
more than one qubit, i. e., the code [ [n, 1:m′,d ] ]2 is in fact a
hybrid code with parameters [ [n,k :m′−k + 1,d ] ]2.
Ford = 4 andd = 5, we have exhaustively searched using all
self-dual codes listed in [ ?], [?] up to n = 11. For d = 3, we
have exhaustively searched all self-dual codes listed in [ ?], [?]
up to n = 10. We also have conducted randomized search for
n = 11. Finally, we appended some qubits in the state |0⟩ to
good quantum codes and found new hybrid codes. The results
are summarized as follows.
